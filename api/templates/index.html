delivery-eta

가게에서 배달지까지의 거리와 밀려 있는 주문 수로 배달 예상 시간(분)을 계산하는 API 입니다.

현재 구현체: {{ model }}

엔드포인트

메서드경로설명
GET/health서비스 상태와 현재 구현체 이름
POST/eta배달 예상 시간 계산
GET/docs대화형 API 문서 (Swagger UI)

요청 예시

POST /eta
Content-Type: application/json

{"distance_km": 2.0, "pending_orders": 3}

응답

{"minutes": 22.0, "model": "{{ model }}"}

distance_km 는 0 이상의 숫자, pending_orders 는 0 이상의 정수여야 하며, 어기면 422 를 돌려줍니다.
